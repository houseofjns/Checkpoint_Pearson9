# House of J&S — Year 9 Computing Learning Portal

## Start the website
1. Extract this ZIP into a folder.
2. Put the centre logo image in the same folder as `index.html`, named exactly `logo1.png`.
3. Open `index.html` in Chrome, Edge, Firefox or Safari.
4. Sign in with any student name and password: `HJSPearson92026`.

## Study chapter list
1. Computer Systems: hardware, software, CPU, memory, devices, operating systems and utilities.
2. Data Representation: binary conversion, binary addition, bits, bytes and storage units.
3. Networks: PAN/LAN/MAN/WAN/VPN, network devices, wired/wireless, bandwidth and throughput.
4. Internet: Internet vs WWW, URLs, DNS, HTTP/HTTPS and packet switching.
5. Digital Safety: personal data, digital footprint, malware, phishing, protection, copyright, wellbeing and e-waste.
6. Programming: variables, data types, operators, selection, iteration, procedures/functions, testing and debugging.
7. Algorithms: flowchart symbols, pseudocode, tracing, searching, sorting, decomposition and abstraction.
8. Data Structures: lists, strings, indexing, trace tables, modelling, validation and verification.

## Marking guidance
The Marking Guide is based on general guidance and examples in the Pearson mark-scheme PDFs supplied with this project. It explains common approaches, but the exact question-specific official mark scheme always takes priority. A mark allocation is not automatically the same for every question: follow the question's own marking instructions, accepted alternatives, exclusions and maximum marks.

## Original exam resources
The 25 supplied PDF files are preserved in `resources/`, with question papers, mark schemes and examiner reports for the available 2020–2024 sessions. They are original source documents and are not modified.

## Important limitations
- The original PDFs are included, but not every question has been transcribed into a fully interactive digital exam.
- This portal does not claim to automatically award official marks for every written answer in every source paper.
- The local login and progress tracker use browser storage. This is not a server-secure authentication system and progress does not automatically sync between devices.
- Study notes are teaching explanations based on the supplied source-paper themes; they are not a replacement for the official Pearson specification or textbook.
